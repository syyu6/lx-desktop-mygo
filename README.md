# 网易云音乐 · MyGo

用 Go 和 [MyGo](https://github.com/egoist/mygo) 写的第三方网易云音乐桌面客户端，原生界面，无 WebView。

## 功能

- 扫码登录，登录态保存在系统凭据存储中
- 每日推荐、推荐歌单、排行榜、我的歌单；歌手、专辑与用户页
- 聚合搜索：单曲与歌单同时询问所有开启的来源，每行标出来自哪个平台，也可只看其中一个；搜索建议与历史
- 播客：浏览与收听节目，订阅播客；在本机把节目转写成字幕（Qwen3-ASR），像歌词一样随播放滚动
- 私人 FM（推荐 / 熟悉 / 探索）与心动模式
- 边下边播，支持标准 / 较高 / 极高 / 无损（FLAC）/ Hi-Res 音质，以及来源给出的 MP3、FLAC、M4A（AAC）与 ADTS
- 提前缓冲下一曲（设置 → 播放，默认开）：当前歌曲播放时预先取好队列里的下一首，切歌不必再等来源给出地址
- 听过的歌曲缓存在本机；音量均衡，暂停与继续时淡出淡入，拖动进度无杂音
- 退出后再打开，从上次的播放队列与进度继续
- 逐字歌词与翻译，正在播放页的「律动」与评论；歌词与评论按来源回退，见下文
- 刘海播放器：在屏幕顶部刘海处显示迷你播放器，悬停展开（在设置中开启）
- 喜欢歌曲、播放队列、随机与循环播放
- 外观四种：跟随系统 / 浅色 / 深色 / 跟随播放器。跟随播放器时，主界面与正在播放页是同一套颜色，随当前封面逐首变色，换歌时约 0.65 秒渐变过去，「每日推荐」页也跟着；播放时一律是沉浸的深色，没有歌曲在放时跟随系统
- 歌单：按分类浏览歌单广场，搜索歌单，订阅其它来源的歌单（粘贴链接或编号），打开应用时自动更新
- 内置源：网易云音乐、酷我音乐、酷狗音乐、QQ 音乐、咪咕音乐；音源脚本可导入[落雪音源](https://github.com/lyswhut/lx-music-desktop)，排在所有内置源之前
- 侧边栏可折叠成图标栏，折叠按钮固定在窗口右上角，图标与文字在图标栏里左右居中；边缘可拖动调宽
- 设置窗口 620×640，横向四个子 tab：通用、播放、来源、外观

## 内置源与音源脚本

「设置 → 来源」里，上面一组是内置源，下面是音源脚本。

- **内置源**是应用自带的曲库，一个来源一行，用行尾的箭头排序。这份顺序就是搜索顺序、歌词回退顺序与播放顺序
- 每个来源有四个开关：**曲库**（参与搜索，出现在歌单广场）、**单曲**（它的歌能被它播放）、**歌词**（被问歌词）、**评论**（提供评论区）。曲库与单曲是两件事：关掉「单曲」，它的歌仍会被搜到，可以交给别的来源放；关掉「曲库」，它自己的歌照样能放，只是不再出现在搜索里
- 酷狗音乐没有可直接播放的地址，所以只作为曲库：搜得到、提供歌词，播放留给能放它的音源脚本
- **音源脚本**是[落雪音源](https://github.com/lyswhut/lx-music-desktop) 的 `.js`，可从网址或本地文件导入，可单独开关、排序、更新（按导入时的网址重新拉取，保留排序与开关）与删除

播放时先问歌曲自己的来源，先由音源脚本、再由内置源；放不了（如需要 VIP）就在其它来源里搜同名歌曲，第一个能播放的放它，失败就换下一个：

- 播放栏标出这首歌实际由哪个来源提供
- 音源给出了地址却打不开时，跳过它继续问下一个；全部试过才报失败
- 关闭网易云音乐的曲库后，侧边栏只留歌单、搜索与订阅的歌单，已加入队列的歌仍可播放
- 歌手、专辑、用户与播客只有网易云有，曲库关闭时这些标签不显示

歌词按「内置源」的顺序回退：自己的来源没有歌词（网易云很多纯音乐就是这样），就去下一个来源找同名歌曲的歌词。评论则回退到网易云，其它平台播放的歌也用它的评论区。

## 音源脚本的沙箱

脚本在 QuickJS（纯 Go 移植，不涉及 cgo）的沙箱里执行，整个应用仍以 `CGO_ENABLED=0` 构建：

- 运行时是裸的：没有文件系统与模块加载器，`import` 任何模块都会被拒绝，读不到本机的文件，也无法结束应用
- 网络只能经由应用：`lx.request` 转给 Go，方法与超时受控，单个响应的上限是 2 MB
- 有内存上限、栈深度上限、启动与单次请求超时；死循环的脚本会被中断并停用，不会拖住应用
- 返回值按 lx-music-desktop 的规则校验（播放地址限 http(s)，歌词与封面有大小上限）
- 脚本支持哪些平台（`kw` `kg` `tx` `wy` `mg`）由它的运行时读出，存在脚本旁边，之后列出来不再为此启动运行时；一分半没用到的运行时会关掉，内存交还系统，设置 → 来源会显示当前有几个在跑
- 应用本身不带任何音源脚本；导入的脚本来自网络，请只导入你信任的来源

脚本只能提供播放地址、歌词与封面，搜索与歌手、专辑、歌单这些目录信息由内置源提供；脚本提供的歌曲不写入歌曲缓存。解码 AAC（M4A）的 FAAD2 仍编译成 WebAssembly，由 wazero 运行。

## 构建

需要 Go 1.27+。

```bash
go tool mygo dev     # 开发模式运行
go tool mygo build   # 打包到 build/
go test ./...        # 运行测试
```
